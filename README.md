自研2D平面激光雕刻控制系统：上位机把图片转成灰度数组，STM32F405以光栅逐点扫描方式驱动XY步进平台，激光按像素灰度做脉冲宽度调制。
- 雕刻精度约 0.1 mm / 像素，理论精度可达 0.03mm / 像素，需要硬件支持！
- 灰度256级调制（越黑，该点出光时间越长）
- 弓字形往返扫描，逐点独立调制
- 上位机（Qt）+下位机（STM32F405RGT6）
- 代码全部开源

- 注意事项：
  由于作者原因，将PA15引脚作为了激光的控制引脚，而PA15又是默认上拉的，所以如果你们的激光是高电平出光的话，请在configure.h里将PA15改成其他引脚，
  并联同PCB文件一起修修改，不修改的话可能会导致单片机在复位那一刻和未上电时会触发激光打开！！！
  PCB那边最好在加一个上拉或下拉电阻，到底为上拉还是下拉得看自己激光驱动器的驱动电平！
